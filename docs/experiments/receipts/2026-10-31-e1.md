## Findings

1. **Baseline placeholder defect (fixed).** The first baseline measured before init and recorded placeholder descriptions and empty schemas. The corrected values are 8.4× the description bytes and 3.5× the schema bytes of the draft. The writer and proof now reject the placeholder era.
2. **Thread digest contract.** `thread(action: "list")` prints a 16-character digest prefix, while `thread(action: "read", digest: …)` requires 64 lowercase hex characters. A listed pack cannot be read by the digest the list shows. `thread(read, handoffId)` is additionally quarantined by `prev_agent_output_envelope`. The context-continue procedure cannot complete its read step against the shipped tool.
3. **First-response guard and auto-pause.** `handoff` is in `TASK_TOOL_NAMES`, so `first-response-guard` requires a prior assistant text part. A first-action handoff is refused before it can run. The health tracker then auto-pauses the agent after 68 seconds, and `resume()` is itself blocked by `agentAutoPauseGuard`, a circular block. The handoff-triage procedure could not mutate the seeded ledger.
4. **Handoff discovery.** `show_board` and `timeline` did not expose the seeded handoffs; the model recovered the ledger only from the seeded record `R-001`. The handoff procedure needs a discovery step that reads the record/ledger, or the board needs to expose handoffs.
5. **Command expansion.** `/tawassul-goals` is registered but does not expand in `opencode run`; `session_message.user.text` stores the literal text. Expansion remains unverified outside the TUI.
6. **Fresh-workspace model route.** The generated minimal contract selected `nvidia/deepseek-ai/deepseek-v4.1-flash` for the dev agent. After the 2026-11-01 boundary the provider returned `provider.no-route: Model unavailable`. One `handoff-off` attempt failed for that reason; the isolated `opencode.json` was repointed to `opencode/big-pickle` and the run repeated. The live repository config uses `google/gemini-flash-lite-latest` and was unaffected. The model catalog and failover path need a review before a fresh workspace relies on that default.
